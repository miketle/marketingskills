## Step 5.3: Site Architecture Improvements

### A. Create Hub Pages for Orphaned Verticals

Currently, `/construction-trades/` and `/medical/` sit at root level with no parent hub. Options:

**Option 1**: Create an `/industries/` hub page
```
/industries/
├── /industries/construction-trades/  (301 redirect from /construction-trades/)
├── /industries/medical/
├── /industries/hospitality/  (future)
└── /industries/retail/  (future)
```

**Option 2**: Keep at root but add consistent navigation
- Add both pages to the main navigation menu under a "Industries" dropdown
- Ensure both appear in footer links
- Add cross-links between them

Recommendation: **Option 2** for now (simpler, avoids URL changes). Move to Option 1 when adding more industry pages.

## Step 5.6: Algorithm Update Preparedness

### When a Google Core Update Rolls Out
1. Don't panic — wait for the rollout to complete (usually 2–3 weeks)
2. Compare before/after traffic in Google Analytics
3. Identify which pages gained or lost
4. Review Google's official guidance for the update
5. Cross-reference lost pages against E-E-A-T checklist
6. Make quality improvements (not reactive "SEO tricks")
7. Wait for the next core update to see recovery

### Ongoing E-E-A-T Maintenance
- Every page should have a visible author with credentials
- Every page should have a "last updated" date
- Update content whenever tax rules change
- Add new case studies and testimonials regularly
- Build the brand's online presence (social, PR, directory listings)
