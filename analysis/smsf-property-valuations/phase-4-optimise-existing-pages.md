## 4.7 Sitewide Optimisation

### Meta Descriptions

Write unique meta descriptions for every page. Each should:
- Be 150-160 characters
- Include the primary keyword
- Include a value proposition (pricing, speed, compliance)
- End with a soft CTA ("Order online" / "Get your report")

### Image Alt Tags

For every image on the site:
- [ ] Add descriptive alt text
- [ ] Include keywords naturally (don't stuff)
- [ ] Example: `alt="SMSF property valuation report sample page showing comparable sales analysis"`

### Internal Linking Structure

Create a hub-and-spoke model:

```
Homepage (hub)
├── → Residential Valuations
├── → Commercial Valuations
├── → Division 296 Guide
├── → For Accountants
├── → City Pages (all)
│
Each spoke links to:
├── → Homepage
├── → Related service pages
├── → ATO Requirements guide
└── → Order/Contact
```

Every page should have:
- At least 2-3 internal links to other relevant pages
- A clear CTA linking to the order/contact page
- A link back to the homepage
