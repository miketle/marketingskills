## Critical: Site Returns 403 Errors

Multiple attempts to fetch the homepage, subpages, sitemap.xml, and robots.txt all returned **HTTP 403 (Forbidden)** errors. This is the single most important issue to investigate.

### Possible Causes
1. **Overly aggressive security plugin** (e.g., Wordfence, Sucuri, All In One WP Security) blocking non-browser user agents
2. **Cloudflare or hosting-level firewall** blocking automated requests
3. **robots.txt misconfiguration** combined with server-side enforcement
4. **IP-based or geo-based blocking** that may inadvertently block crawlers

### Why This Matters
- If Googlebot receives 403 errors, pages **will not be indexed**
- If the site currently ranks, it's possible Google cached earlier crawls — but rankings will decay
- Analysis tools (Ahrefs, SEMrush, Screaming Frog) cannot audit the site
- Potential customers using VPNs or corporate networks may also be blocked

### How to Diagnose
1. Check Google Search Console for crawl errors (Coverage → Excluded → "Blocked by robots.txt" or "Crawled — currently not indexed")
2. Test with Google's URL Inspection tool — does it render correctly?
3. Review server access logs for Googlebot visits and response codes
4. Check WordPress security plugins for "Block unknown user agents" settings
5. If using Cloudflare: check Firewall Events for blocked Googlebot requests
6. Test: `curl -A "Googlebot" https://smsfpropertyvaluations.com.au`

## Duplicate Content Issues

### Duplicate Homepage
- **`/`** and **`/home-2/`** both serve as homepages
- WordPress sometimes creates these during theme changes or page builder updates

**Fix:** 301 redirect `/home-2/` → `/` and ensure only one page is set as the static front page in WordPress Settings → Reading.

### Near-Duplicate Content Pages
These page pairs target nearly identical topics:

| Page A | Page B | Overlap |
|---|---|---|
| `/commercial-property-value/` | `/commercial-property-values-2/` | Same topic, "-2" suffix |
| `/commercial-property-valuation-calculator/` | `/free-commercial-property-valuation-calculator/` | Same tool, different URL |
| `/commercial-property-valuation-free/` | `/commercial-property-valuation-calculator/` | Same concept |
| `/best-commercial-property-valuations/` | `/commercial-property-valuations/` | Same service |

**Fix:** Choose one canonical URL per topic. 301 redirect the others. Or differentiate content clearly (e.g., one targets "calculator" intent, another targets "how valuations work").

2. Optimise images with WebP format (ShortPixel, Imagify)
3. Minify CSS/JS
4. Use a CDN (Cloudflare — may already be in place given the 403 behavior)
5. Lazy load images below the fold
6. Reduce unused plugins
